# Top Eleven AI Agent

Aktivna verzija projekta nalazi se u folderu `AI-Agent`.

Pokretanje:

1. Otvorite `AI-Agent`.
2. Pokrenite `Pokreni AI Agent.cmd` za centralnu aplikaciju sa izborom svih skripti.

Centralna aplikacija prikazuje log, omogucava sigurno zaustavljanje, izbor pocetne faze za `Pokreni sve` i izbor pocetne pozicije za odmor igraca.

Za kompletnu lokalnu provjeru bez pokretanja BlueStacksa koristi dugme `Provjeri projekat` u Postavkama ili pokreni `AI-Agent\Provjeri projekat.cmd`.

Za desktop precicu pokrenite `Napravi desktop precicu.ps1`; precica vodi na aktivni AI izbornik.

Detaljna dokumentacija je u `AI-Agent/README_AI.md` i `AI-Agent/README_SVE_REDOM.md`.
